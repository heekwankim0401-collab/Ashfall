# ASHFALL (가제)

재로 덮인 붉은 황무지에 들어가 물자를 챙기고, 죽으면 전부 잃는다. 살아서 탈출 지점에 도달해야만 가져온 것이 내 것이 된다.

1인칭 싱글플레이 하드코어 익스트랙션 슈터 — Unity 6 (6000.3.26f1), URP, Windows.

> **MVP 프로토타입(v0.1.1)입니다.** 무기·적·차량·건물 등 일부 3D 모델은 에셋스토어 무료 모델(릴리스 빌드에만 포함), 소리와 나머지 모델·텍스처는 코드로 만든 자리표시이고, 무기·경제·적 수치는 플레이 검증 전 기본값입니다.

## 바로 플레이하기

1. [Releases](../../releases/latest)에서 `Ashfall-Windows64-v0.1.1.zip`을 내려받습니다.
2. 압축을 풀고 `Ashfall.exe`를 실행합니다.
   - Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누릅니다(서명되지 않은 실행 파일이라 뜹니다).
3. 메인 메뉴 → 은신처 → 레이드 순서로 시작합니다. 처음에는 은신처에서 무료 "부랑자 키트"를 받을 수 있습니다.

**권장 사양:** Windows 10/11 64비트, GTX 1660급 GPU, 16GB RAM (목표 1080p 60fps).
노트북 내장 그래픽(예: Intel HD 620)에서는 1080p 약 30fps, 720p 60fps 이상(프레임 약 13ms)으로 측정됐습니다.

세이브는 `%USERPROFILE%\AppData\LocalLow\DefaultCompany\Ashfall\save.json`에 저장됩니다(은신처에 들어갈 때만 기록).

## 규칙

- **사망하면 레이드에 가져간 모든 것을 잃습니다.** 보험은 없습니다.
- 레이드 제한 시간은 25분. 넘기면 MIA(=사망) 처리됩니다.
- 레이드 중 게임을 강제로 끄면 사망으로 처리됩니다.
- 화면 아래에 HUD가 있습니다: 부위별 체력, 상태이상, 스태미나·수분·에너지, 무기 탄 수·예비 탄창, 레이드 남은 시간, 피격 방향 표시.
- 미니맵과 크로스헤어는 없습니다. 정확히 쏘려면 정조준(우클릭)하고, 위치는 종이 지도(M)로 확인합니다.

## 들어 있는 것 (MVP)

- **무기 5종:** 녹슨 권총, 개조 SMG, 군용 소총, 펌프 샷건, 볼트액션 — 탄도 투사체(낙차·공기 저항·무기별 영점), 무기별 가늠자 정조준, 탄창별 실제 탄 수, 고장·내구도(상인 수리)
- **부위별 체력과 상태이상:** 출혈·중출혈·골절·방사능·탈수·허기, 방어구 관통·둔탁 피해
- **그리드 인벤토리:** 회전, 장착 슬롯, 루트 컨테이너 검색
- **적 AI:** 약탈자, 레이더, 저격수, 변이체, 보스 "재의 군주"와 호위
- **맵 "붉은 계곡":** 1km × 1km, 탈출 지점 4곳, 재 폭풍 이벤트
- **은신처:** 보관함(업그레이드), 상인, 제작대, 부랑자 키트

## 소스에서 빌드하기

1. Unity Hub에 **Unity 6000.3.26f1**과 **Windows Build Support (IL2CPP)** 모듈을 설치합니다.
2. Visual Studio 2022 이상에 **C++를 사용한 게임 개발** 워크로드를 설치합니다.
3. 이 저장소를 받아 Unity Hub에서 폴더를 엽니다(첫 가져오기는 시간이 걸립니다).
   - 릴리스 빌드의 3D 모델(에셋스토어 무료 패키지)은 라이선스상 저장소에 없습니다. 받은 저장소에서는 메뉴 `Ashfall/Setup/Apply Asset Swap`을 한 번 실행해
     빈 모델 자리를 정리하세요(자리표시 블록 모습이 되고, 실행 전에는 레이드 씬을 열 때 Missing Prefab 오류가 납니다).
4. 메뉴 `File → Build Profiles`에서 Windows로 빌드하거나, 배치모드로 `Ashfall.EditorTools.BuildTools`의 빌드 메서드를 실행합니다.
