# 맵 개선 리뷰 (code-reviewer, 2026-10-26)

대상: `docs/design/MapPolish_design.md` 구현(커밋 전 작업 트리). §13.3 규칙 위반 없음(런타임 변경은 `AtmosphereConfigSO`뿐, 새 싱글톤·옛 입력 없음, 실내 없음).
성능(그림자 없는 점광원 14·Forward+·정적 배칭)·멱등성("없을 때만"·개정 번호·광원 값 비교)은 문제 없음. 처리 결과는 각 줄 끝 → 표시.

## 높음
- **H1** `RebakeNavMesh`가 확인 전에 NavMesh 에셋을 저장 → 굽기 뒤 확인이 실패하면 씬은 안 바뀌고 NavMesh만 구조물 구멍을 가진 채 남는다.
  → 굽기 전 에셋 바이트를 보관하고 실패하면 되돌린다(재가져오기).
- **H2** `Build` 중간 예외 뒤 에디터에서 열린 씬(그룹 일부 생성, dirty)을 사람이 저장하면 다음 실행은 "그룹 있음"으로 확인·굽기를 건너뛴다.
  → 실패 시 만든 그룹을 지우고 NavMesh를 되돌린다. "그룹 있음" 쪽에서도 구조물 자리가 NavMesh에 구멍으로 반영됐는지 확인(아니면 예외 — Rebuild 메뉴 안내).

## 중간
- **M1** 굽기 뒤 도달성은 스폰 → 탈출만 경로로 본다(상자·적·새 엄폐는 근처 NavMesh만). 구조물 윗면에 닿을 수 없는 NavMesh 섬이 생긴다.
  → 기준 스폰에서 상자·적 시작점까지 경로 Complete를 굽기 전과 비교(회귀만 실패), 새 엄폐 지점은 도달 못 하면 뺀다. 맵 개선 그룹 루트에 NavMeshModifier(Not Walkable)로 윗면 섬 제거.
- **M2** 엄폐 지점 PlayMode 테스트는 옛 NavMesh에서도 통과한다. → 구조물 중심 지면이 NavMesh 밖(구멍)인지 확인하는 테스트 추가.
- **M3** `Layout_Check_DetectsConflicts`가 실제로 검출을 시험하지 않는다. → 항목 주입 오버로드 + 도로·스폰·POI·저격 시선 위 항목이 걸리는지 시험.
- **M4** 같은 경로에 모델 프리팹을 덮어써도 그룹이 있어 겹침 확인·다시 굽기가 돌지 않는다. → `Ashfall/Setup/Map Polish/Rebuild`(그룹 지우고 다시 적용) 추가, 교체 절차 문서화.
  팔레트 머티리얼·GroundSurface 단언은 교체 때 함께 고칠 대상으로 문서에 적는다.
- **M5** 개정 1 밝기 값이 에디터 상수에만 있고 SO 필드 초기값은 옛 값. → 필드 초기값 = 개정 1 값(개정 번호 기본 0), 상수는 이전(마이그레이션) 용도.
- **M6** 래퍼를 발자국 최저 지면에 놓아 경사 위쪽 면이 묻히는데 엄폐 높이는 사양값으로 정한다(동체 위쪽 면 노출 약 1.35m 등), 잔불 광원이 지형 안일 수 있다.
  → 엄폐 지점마다 드러난 높이를 계산해 High → Low로 내리거나 빼고, 광원은 지면 위로 올린다.

## 낮음
- L1 겹침 쿼리 버퍼(64·16)가 차면 조용히 잘림 → 버퍼를 늘리고 가득 차면 오류.
- L2 peek 지점이 콜라이더 안일 수 있음 → peek도 캡슐 검사, 막히면 그 엄폐 지점을 뺀다.
- L3 전원 스위치 회피 거리 10m/5m/문서 25m 불일치 → 상수 하나(10m)로 통일, 문서 수정.
- L4 문서 불일치(라디오 마스트 위치, 송전탑 높이 36m → 약 30m, 구현 메모 비어 있음) → 문서 수정.
- L5 Low/High 기준 1.3m 리터럴 중복 → 공용 상수.
- L6 시선 검사가 넘겨받은 지형 대신 `FindFirstObjectByType<Terrain>` → 넘겨받은 지형 사용.
- L7 광원 수를 씬 전체로 셈 → 상한 확인은 씬 전체(성능 목적) 그대로, PlayMode 테스트의 "정확히 14"는 맵 개선 그룹만 센다.
- L8 밝기 개정·볼륨이 씬 단계보다 먼저 저장 → 씬 단계 실패 시 다시 실행하면 해소(문서화만).
- L9 회귀 키가 이름 → 인스턴스 ID 키.
- L10 테스트 색 기대값이 코드와 같은 식 → 적용 여부 확인용임을 인정(그대로).
- L11 루트의 `polish_orig*.log` → 커밋 전에 지운다.
