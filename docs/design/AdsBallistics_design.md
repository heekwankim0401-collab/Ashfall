## 2. 가늠자 기준점 (AB-Q1)
- VM 프리팹 자식 `SightAnchor`: 위치 = 가늠자 뒤쪽 기준점(구멍 가늠자 = 구멍 중심, 홈 가늠자 = 홈 윗면), +z = 가늠쇠 끝 방향(시선).
- 값은 `EditorTools/WeaponSightLayout`(원본 패키지 좌표). 스킨 프리팹 구조(SK 루트 → 합친 자식 localPosition = -앵커, 원본 회전 Euler)로 VM 로컬로 옮겨
  `Apply Asset Swap`이 스킨 크기·위치를 바꿔도 같은 부품 위에 온다. 스킨이 없으면 블록아웃 값.
- 조사 도구 `WeaponSightProbe`: `Report Sight Geometry`(부품별 원본 좌표 윤곽), `ReportVertices`(배치 `-ashfallSightQuery`), `RenderViews`(옆·뒤 직교 PNG).
- 무기별 결과(VM 로컬, m): 앵커 → 가늠쇠, 시선 기울기

| 무기 | 근거 부품 | 앵커 | 가늠쇠 | 기울기 |
|---|---|---|---|---|
| PST | BarrelGuard.001 뒤 블록 윗면 / 앞 기둥 | (0, 0.0737, -0.0546) | (0, 0.0734, 0.0977) | 0.13° |
| SMG | Sight_Back_Part 구멍 / Sight_Front_Part 기둥 | (0.0019, 0.1184, 0.0481) | (0.0019, 0.1189, 0.2136) | -0.20° |

  DMR 스킨(Recon_P)은 조준경이 없는 가늠자 모델이다. 가늠쇠 끝이 홈 바닥보다 낮아 시선이 0.74° 기울고, 정조준 때 뷰모델을 그만큼 든다.
- 정조준 자세(`AdsAlignment.ViewRootPose`): 앵커가 카메라 정면 축 위 `adsEyeReliefM` 앞, 앵커 회전 = 카메라 회전. 무기 정의마다 장착 시 1회 계산(캐시).
  지향 ↔ 정조준은 위치 Lerp + 회전 Slerp. `adsEyeReliefM` 0 또는 앵커 없음 → 컨트롤러 `adsLocalPosition`(폴백).

## 3. 영점 (AB-Q2)
- `BallisticZero.TrySolve`: 눈 좌표(시선 +z, 수평 조준 가정, 중력 -y)에서 정조준 총구 위치를 떠난 탄이 (0, 0, zeroRange)를 지나는 방향.
  좌우는 직선(저항은 속도 방향이라 수평 진행 방향 불변), 높이는 할선법(허용 1e-5m). 게임과 같은 `Ballistics.Step`·`Time.fixedDeltaTime`·구간 선형 보간.
- 사격: 영점이 있으면 `transform.rotation × 영점 방향`(흔들림 포함), 없으면 `transform.forward`. 지향 사격도 같은 방향(총에 고정된 영점).

## 4. 공기 저항 (AB-Q3)
- `AmmoDefinitionSO.dragPerM` k: a = g - k|v|v. k = 0 → 예전 반암시적 오일러(비트 단위 동일).
- k > 0 스텝: v' = v/(1 + k|v|dt) + g·dt, p += (v + v')/2·dt (제곱근 1·나눗셈 1). 반암시적 오일러는 dt 0.02에서 200m 낙차가 RK4 대비 약 3% 어긋났다(권총 4.2cm/1.29m).
- 값: 9mm 0.0020, 5.56 0.0011, 7.62 0.0008, 12ga 0.0040 (200m 탄속 -33%/-20%/-15%/-55%).
- 최대 비행 시간 안 사거리 감소(수평 근사 s = ln(1 + k·v0·t)/k): 9mm 약 540→366m, 5.56 약 2700→1250m, 7.62 약 2460→1360m, 12ga 약 320→206m.

## 6. 남은 위험
- **후속 과제:** 총구 `Muzzle` 자식이 스킨 총열보다 약 5~6cm 아래(에셋 교체가 스킨 앞면 경계 중심을 Muzzle에 맞춤). 탄 출발점 = Muzzle이라 시선 높이가 실제 총보다 크다 —
  영점은 이 위치로 계산하므로 명중은 맞지만, 근거리(영점 앞) 탄착이 실제보다 낮다(10m에서 4~10cm). Muzzle을 옮기면 스킨 배치도 함께 바꿔야 한다(후속).
- 사람 플레이 확인 전: 눈 거리(권총 0.30m는 화면에서 작게 보임)·영점 거리는 임시값. 근평면 0.05m에 가까운 개머리 부분이 화면 아래에서 잘릴 수 있다.
- 영점은 수평 조준 기준(실제 총과 같음). 크게 위·아래로 쏘면 영점 거리에서도 조금 빗나간다.
- AI는 낙차 보정 없음(AB-Q4).
